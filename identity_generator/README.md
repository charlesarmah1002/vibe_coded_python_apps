# Dark Identity Generator

A sleek, dark-themed generator for usernames and real names built with Python and Tkinter.

## Features
- **Dual Mode**: Switch between Username and Real Name generation.
- **Dark Mode UI**: Modern aesthetic with a clean, intuitive interface.
- **Adjustable Length**: Custom sliders to control the length of usernames and names.
- **Customizable Options**: Toggle numbers, special characters, or middle initials.
- **One-Click Copy**: Quickly copy results to your clipboard.

## How to Run
1. Ensure you have Python installed.
2. Install Tkinter if you don't have it:
   ```bash
   sudo apt-get install python3-tk  # Linux
   ```
3. Run the application:
   ```bash
   python3 app.py
   ```

## Files
- `app.py`: The main GUI application.
- `logic.py`: The core generation logic (can be used as a standalone module).
- `identity_generator.exe`: This is the bundled app [click here to download](https://github.com/charlesarmah1002/vibe_coded_python_apps/blob/main/identity_generator/identity_generator.exe)
